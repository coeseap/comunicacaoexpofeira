# Caderno de Comunicacao Expofeira 2026

Versao estatica 2.0 preparada para publicacao no GitHub Pages.

## Publicacao

1. Envie todo o conteudo desta pasta para a raiz do repositorio.
2. Confirme que `index.html`, `styles.css` e `app.js` ficaram na raiz.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/(root)` e clique em **Save**.

Nao ha etapa de compilacao. Preserve os nomes e a estrutura das pastas `assets` e `docs`.
