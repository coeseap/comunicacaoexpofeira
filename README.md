# Caderno de Comunicacao Expofeira 2026

Versao estatica 2.0 preparada para publicacao no GitHub Pages.
Pacote revisado em 8 de agosto de 2026.

## Publicacao

1. Envie todo o conteudo desta pasta para a raiz do repositorio.
2. Confirme que os arquivos abaixo ficaram na raiz:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `programacao-data.js`
   - `expositores-data.js`
   - `news-data.js`
   - `.nojekyll`
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/(root)` e clique em **Save**.

Nao ha etapa de compilacao. Preserve os nomes e a estrutura das pastas `assets` e `docs`.
O diretorio `docs` inclui a Lei Estadual, o Decreto Estadual e a Instrucao Normativa do ICMS para consulta e download.
